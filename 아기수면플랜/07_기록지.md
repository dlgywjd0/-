# 07. 하루 기록지

수면 교육의 90%는 기록입니다. 최소 **1주일**만 적어보면 우리 아기의 진짜 패턴이 보입니다.
인쇄해서 냉장고에 붙이거나, 스프레드시트로 옮겨 쓰세요.

## 기록 양식

```
날짜: 2026-__-__ (생후 ___일)   체중: ___kg

┌───────┬────────────┬────────────┬──────────────────────┐
│ 시각   │ 수유(ml/분) │ 잠(시작~끝) │ 메모 (기분·기저귀·특이사항) │
├───────┼────────────┼────────────┼──────────────────────┤
│ 07:00 │            │ 기상        │                      │
│       │            │            │                      │
│       │            │            │                      │
│       │            │            │                      │
│       │            │            │                      │
│       │            │            │                      │
│       │            │            │                      │
│       │            │            │                      │
│       │            │            │                      │
│ 19:00 │            │ 취침        │                      │
│       │            │            │                      │
│       │            │            │                      │
└───────┴────────────┴────────────┴──────────────────────┘

하루 합계
  기상 시각 ______      취침 시각 ______
  낮잠 횟수 ___회       낮잠 총합 ___시간 ___분
  밤중 각성 ___회       밤중 수유 ___회
  총 수유 ___회         총 수유량 ___ml
  소변 기저귀 ___회     대변 ___회

오늘의 한 줄:  ____________________________________
```

## 스프레드시트용 CSV 헤더

```csv
날짜,생후일수,기상시각,낮잠1시작,낮잠1종료,낮잠2시작,낮잠2종료,낮잠3시작,낮잠3종료,낮잠4시작,낮잠4종료,낮잠총합(분),취침시각,밤중각성횟수,밤중수유횟수,수유횟수,총수유량(ml),소변기저귀,체중(kg),메모
```

## 주간 점검 (일요일 저녁 5분)

- [ ] 기상 시각이 7일 중 5일 이상 ±30분 안에 들어왔는가
- [ ] 낮잠 총합이 3시간 30분~4시간 30분 범위였는가
- [ ] 마지막 낮잠이 17:30 이전에 끝났는가
- [ ] 하루 총 수유량이 목표치(체중 × 150ml)에 근접했는가
- [ ] 밤중 각성 횟수가 지난주보다 줄었는가 (같아도 괜찮습니다)
- [ ] 이번 주 커리큘럼 단계를 지켰는가 → 못 지켰으면 다음 주로 넘기지 말고 **한 주 더 반복**

> 좋아졌다 나빠졌다를 반복하는 것이 정상입니다. 하루 단위가 아니라 **주 단위**로 비교하세요.
