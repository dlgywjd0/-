# 갭 없는 EASY 기본형 — 먹 → 놀 → 잠 (놀 꼬리 제거)

## 문제: 왜 계속 "먹-놀-잠-놀"이 되는가

한 사이클 = **텀 3:50 = 230분**.
여기서 수유 30분을 빼면 **놀 + 잠 = 200분**이어야 갭이 생기지 않는다.

낮잠 총합을 5시간 안에 맞추려고 **낮잠을 2시간 이상 잡았다가 잘라내면**,
놀이가 70분밖에 안 되고 남는 40분이 **낮잠 뒤에 붙어 "놀"이 하나 더 생긴다.**

> **잘라낸 만큼이 낮잠 뒤로 밀린 것뿐이다.**

## 해법: 놀과 잠을 1:40씩 균등 배분

| 구간 | 시간 | 구성 |
|---|---|---|
| 먹 | 30분 | 수유 25분 + 여유 5분 |
| **놀** | **1:40** | 세워두기 30분 → 놀이 55분 → 수면 의식 15분 |
| **잠** | **1:40** | 낮잠 |
| **합** | **3:50** | = 텀 ✓ |

낮잠이 **정확히 다음 수유 시각에 끝나므로 갭이 0**이고,
낮잠 3회 × 1:40 = **정확히 5시간**으로 4개월 기준(3~5h) 상한에 맞는다.

## 기본형 시간표 (기상 06:30 · 취침 19:30)

| 시각 | 구분 | 내용 |
|---|---|---|
| 06:30 | | 기상 |
| 06:40~07:10 | 먹 | **E1** · 텀 시작 |
| 07:10~08:50 | 놀 | 세워두기 30 → 놀이 55 → 수면 의식 15 |
| 08:50~10:30 | 잠 | **S1 1:40** |
| 10:30~11:00 | 먹 | **E2** · 텀 3:50 |
| 11:00~12:40 | 놀 | 동일 구성 |
| 12:40~14:20 | 잠 | **S2 1:40** |
| 14:20~14:50 | 먹 | **E3** · 텀 3:50 |
| 14:50~16:30 | 놀 | 동일 구성 |
| 16:30~18:10 | 잠 | **S3 1:40** |
| 18:10~18:35 | 먹 | **막수** · 텀 3:50 |
| 18:35~19:05 | | 세워두기 30분 → 트림 |
| 19:05~19:15 | 목욕 | 5~7분 |
| 19:15~19:30 | | 보습 + 배 마사지 + 잠옷 |
| **19:30** | 잠 | **취침** |

**총계**: 낮잠 **5:00** · 밤잠 **11:00** · 총 수면 **16:00** · 수유 4회 · 텀 전부 3:50 · **갭 0**

**기상이 07:00이면** 전체를 30분 뒤로 이동 (취침 20:00).

## 이 구조가 성립하는 조건

- **낮잠을 1:40 이상으로 늘리지 않는다.** 늘리면 총합이 5시간을 넘는다.
- **낮잠을 1:40 미만으로 자르지 않는다.** 자르면 그만큼 낮잠 뒤에 "놀" 꼬리가 생긴다.
- 낮잠이 일찍 깨면 **쉬닥법으로 이어 재워 1:40을 채운다.** 이것이 갭을 막는 유일한 방법.
- **잠텀은 2:10**(수유 30 + 놀 1:40)이 된다. 4개월 아기에게 적정하다.

## 저녁 순서

막수 → 세워두기(트림) → **목욕** → 보습·잠옷 → 눕히기.
목욕을 막수 뒤에 두는 이유와 상세는 `05_문제해결_QnA.md`의
"저녁 취침 실패 루프" 항목 참조.
