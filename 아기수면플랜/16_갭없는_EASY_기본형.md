# 갭 없는 EASY 기본형 — 먹 → 놀 → 잠 (놀 꼬리 제거)

## 문제: 왜 계속 "먹-놀-잠-놀"이 되는가

한 사이클 = **텀 3:50 = 230분**.
여기서 수유 블록을 빼면 나머지가 **놀 + 잠**이어야 갭이 생기지 않는다.

아인이는 **먹는 데 15분**이 걸린다. 중간 트림 2회(약 5분)를 더해 **수유 블록 = 20분**.
따라서 **놀 + 잠 = 210분**.

낮잠 총합을 5시간 안에 맞추려고 **낮잠을 2시간 이상 잡았다가 잘라내면**,
놀이가 70분밖에 안 되고 남는 40분이 **낮잠 뒤에 붙어 "놀"이 하나 더 생긴다.**

> **잘라낸 만큼이 낮잠 뒤로 밀린 것뿐이다.**

## 해법: 놀과 잠을 1:40씩 균등 배분

| 구간 | 시간 | 구성 |
|---|---|---|
| 먹 | **20분** | 먹기 15분 + 중간 트림 2회 5분 |
| **놀** | **1:50** | 세워두기 30분 → 놀이 65분 → 수면 의식 15분 |
| **잠** | **1:40** | 낮잠 |
| **합** | **3:50** | = 텀 ✓ |

낮잠이 **정확히 다음 수유 시각에 끝나므로 갭이 0**이고,
낮잠 3회 × 1:40 = **정확히 5시간**으로 4개월 기준(3~5h) 상한에 맞는다.

## 기본형 시간표 (기상 07:00 · 취침 19:55)

| 시각 | 구분 | 내용 |
|---|---|---|

| 08:00~09:05 | 놀 | 놀이 · 터미타임 5분 |
| 09:05~09:20 | | 수면 의식 |

**기상 시각이 달라지면** 전체를 같은 만큼 평행 이동한다.

## 이 구조가 성립하는 조건

- **낮잠을 1:40 이상으로 늘리지 않는다.** 늘리면 총합이 5시간을 넘는다.
- **낮잠을 1:40 미만으로 자르지 않는다.** 자르면 그만큼 낮잠 뒤에 "놀" 꼬리가 생긴다.
- 낮잠이 일찍 깨면 **쉬닥법으로 이어 재워 1:40을 채운다.** 이것이 갭을 막는 유일한 방법.
- **잠텀은 2:10**(수유 20 + 놀 1:50)이 된다. 4개월 아기에게 적정하다.

## 저녁 순서

막수 → 세워두기(트림) → **목욕** → 보습·잠옷 → 눕히기.
목욕을 막수 뒤에 두는 이유와 상세는 `05_문제해결_QnA.md`의
"저녁 취침 실패 루프" 항목 참조.


## 수면 부채가 있을 때의 예외

낮잠이 5시간을 넘어도 되는 유일한 경우는 **전날 총 수면이 기준(14~16h)에 크게 못 미쳤을 때**다.

**조건**: 취침 시각을 지킬 것.
낮잠이 많아도 밤잠 시간이 확보되면 문제없다.
문제는 **낮잠도 많은데 취침까지 늦어질 때** — 총 수면은 그대로인데 밤잠만 깎여 부채가 다시 쌓인다.

**이틀 연속 초과는 금지.** 낮잠 과다가 이틀 이어지면 밤잠이 짧아지며 부채가 재시작된다.
부채는 2~3일에 걸쳐 갚되, 정상화되면 즉시 낮잠 5:00으로 복귀한다.
