# 고정 시간표 (개정) — 낮잠 4회 · 수유 5회

기상 07:00 · 취침 19:15 · 수유 텀 2:45 · **잠텀 1시간 40분** · 갭 0

## 왜 바꾸는가

**아인이의 실제 잠텀 한계는 1시간 35~50분이다.**
(9/1 기록: 07:20 기상 → 09:05에 졸림 신호 1:45 / 11:15 기상 → 12:47에 신호 1:32)

3회 낮잠 안(`17_고정시간표.md`)은 잠텀을 **2시간 20분**으로 잡아야 성립했고,
그 결과 매번 과각성으로 저녁이 무너졌다.

### 산수

> 한 사이클 = **잠텀 + 낮잠**
> 잠텀 1:40 + 낮잠 1:05 = **사이클 2시간 45분**

여기서 수유 텀 3:45를 고집하면 낮잠이 2시간이 되어야 하고,
그러면 잠텀이 다시 2시간을 넘는다. → **텀을 2:45로 줄이고 수유를 5회로 늘린다.**

### 소량 자주가 역류에 유리하다

**역류가 있는 아기에게는 소량 자주가 정석이다.**
190~230ml 4회보다 **160~200ml 5회**가 게워냄이 훨씬 적다.
8/31 아침 구토, 8/30 밤 전량 구토 모두 큰 양이 원인이었다.

## 왜 수유 4회로는 갭 0이 안 되는가

**텀 3:40 = 220분.** 수유 15분을 빼면 **놀 + 잠 = 205분**이어야 낮잠이 다음 수유에 딱 끝난다.

| 낮잠 길이 | 놀이 | 잠텀 | 낮잠 총합 | 총 수면 |
|---|---|---|---|---|
| 1:25 × 3 | 2:00 | **2:15** | 4:15 | 16:00 |
| 1:40 × 3 | 1:45 | 2:00 | 5:00 | **16:45** 초과 |

→ 잠텀 1:45 이하 · 갭 0 · 총 수면 16h 이내를 **동시에 만족할 수 없다.**

**텀 2:45(5회)면** 165분 = 수유 15 + **놀 1:25 + 잠 1:05** → **잠텀 1:40**으로 전부 맞는다.

## 수유량 — 하루 총량 상한 960ml (밤수 포함)

### 기준

아인이는 **체중이 높은 편**(62cm / 7.6kg 시점 weight-for-length 상위)이므로
**하루 총량 상한 960ml**를 지킨다. **밤수까지 합산한 값**이다.

### 밤수를 줄여가는 동안의 배분

낮 + 밤 합계를 항상 **960 이하**로 두고, 밤수가 줄어드는 만큼 낮을 올린다.

| 단계 | 밤수 | 낮 총량 | 합계 |
|---|---|---|---|
| 1~3일 | 130ml | **830ml** | 960 |
| 4~7일 | 100ml | 860ml | 960 |
| 1~2주 | 60ml | 900ml | 960 |
| 끊은 뒤 | **0** | 900~940ml | ≤960 |

### 낮 830ml 단계 배분

| | 시각 | 양 | 비고 |
|---|---|---|---|
| E1 | 07:15 | **190ml** | 아침이 가장 배고픔 |
| E2 | 10:00 | **160ml** | |
| E3 | 12:45 | **150ml** | |
| E4 | 15:30 | **130ml** | **막수를 크게 먹이려 줄임 — 핵심** |
| 막수 | 18:15 | **200ml** | 밤잠 길이를 좌우 |
| | **합계** | **830ml** | |

> **막수 200ml는 어떤 단계에서도 유지한다.** 줄이는 것은 E2·E3·E4에서만.
> 막수가 작아지면 밤에 더 깨고, 그러면 밤수가 늘어 총량이 오히려 초과된다.

### 체중 관점

**밤중 수유를 없애는 것이 체중 관리에도 유리하다.**
밤에 먹는 칼로리는 활동으로 소비되지 않고 축적된다. 같은 960ml라도 낮이 낫다.

소아과에서는 **성장 곡선의 체중·키 백분위를 함께** 확인할 것.
몸무게만 보면 과대평가된다.

### 양을 줄였을 때 배고파하면

더 주지 말고 —
- **젖꼭지를 한 단계 작은 것으로** (천천히 먹으면 포만감이 제대로 온다)
- 수유 후 **쪽쪽이**
- 안아주고 놀아주며 다음 수유까지 넘기기

**다음 수유가 2:45마다 오므로 오래 기다리지 않는다.** 5회로 나눈 이유이기도 하다.

**E4를 160으로 줄이는 것이 포인트.** 여기서 배부르면 막수 200ml를 못 먹고, 그러면 밤에 깬다.
E4에서 배고파 울면 180까지는 허용하되, **막수는 무조건 200 목표.**

### 소화

텀 2:45 = 수유 15분을 빼면 **위가 비어 있는 시간 2:30**.
170~180ml는 2:30이면 대부분 비워진다. 190ml인 E1만 다음 텀이 2:47로 조금 길다.

## 밤수 끊기 — 2주 계획

### 1주차

- **낮 900ml를 확실히 채운다** (이것이 8할)
- **막수 200ml 사수** — 먹다 잠들면 깨워서 다 먹인다
- 깼을 때: **쪽쪽이 → 쉬닥법 5~10분** → 그래도 안 되면 먹이되 **매일 30ml씩 감량**
  (160 → 130 → 100 → 70 → 40)

### 2주차

- **40ml까지 내려가면 배고파서가 아니라 습관이다.**
- 그때부터 물리지 말고 **쉬닥법만 15분.** 2~3일이면 끊긴다.

### 금지

**밤수를 갑자기 끊지 않는다.** 낮 총량이 안 채워진 상태에서 끊으면
새벽에 더 자주 깨고 아침에 폭식한다.
