# 고정 시간표 (개정) — 낮잠 4회 · 수유 5회

기상 07:00 · 취침 19:15 · 수유 텀 2:45 · **잠텀 1시간 40분** · 갭 0

## 왜 바꾸는가

**아인이의 실제 잠텀 한계는 1시간 35~50분이다.**
(9/1 기록: 07:20 기상 → 09:05에 졸림 신호 1:45 / 11:15 기상 → 12:47에 신호 1:32)

3회 낮잠 안(`17_고정시간표.md`)은 잠텀을 **2시간 20분**으로 잡아야 성립했고,
그 결과 매번 과각성으로 저녁이 무너졌다.

### 산수

> 한 사이클 = **잠텀 + 낮잠**
> 잠텀 1:40 + 낮잠 1:05 = **사이클 2시간 45분**

여기서 수유 텀 3:45를 고집하면 낮잠이 2시간이 되어야 하고,
그러면 잠텀이 다시 2시간을 넘는다. → **텀을 2:45로 줄이고 수유를 5회로 늘린다.**

### 소량 자주가 역류에 유리하다

**역류가 있는 아기에게는 소량 자주가 정석이다.**
190~230ml 4회보다 **160~200ml 5회**가 게워냄이 훨씬 적다.
8/31 아침 구토, 8/30 밤 전량 구토 모두 큰 양이 원인이었다.

## 수유량 — 하루 총 900ml

### 기준

4개월은 **체중 1kg당 110~130ml**. 아인이 8kg 안팎이면 **880~1040ml**가 적정.

기존 실적은 낮 700~740ml + 밤수 160ml = **약 880ml**.

> **밤수를 끊으려면 그 160ml를 낮으로 옮겨야 한다.**
> 낮 총량을 그대로 두고 밤수만 빼면 배고파서 더 깬다.

### 배분

| | 시각 | 양 | 비고 |
|---|---|---|---|
| E1 | 07:15 | **190ml** | 아침이 가장 배고픔 |
| E2 | 10:00 | **180ml** | |
| E3 | 12:45 | **170ml** | |
| E4 | 15:30 | **160ml** | **막수를 크게 먹이려 줄임 — 핵심** |
| 막수 | 18:15 | **200ml** | 밤잠 길이를 좌우 |
| | **합계** | **900ml** | 낮에만 |

**E4를 160으로 줄이는 것이 포인트.** 여기서 배부르면 막수 200ml를 못 먹고, 그러면 밤에 깬다.
E4에서 배고파 울면 180까지는 허용하되, **막수는 무조건 200 목표.**

### 소화

텀 2:45 = 수유 15분을 빼면 **위가 비어 있는 시간 2:30**.
170~180ml는 2:30이면 대부분 비워진다. 190ml인 E1만 다음 텀이 2:47로 조금 길다.

## 밤수 끊기 — 2주 계획

### 1주차

- **낮 900ml를 확실히 채운다** (이것이 8할)
- **막수 200ml 사수** — 먹다 잠들면 깨워서 다 먹인다
- 깼을 때: **쪽쪽이 → 쉬닥법 5~10분** → 그래도 안 되면 먹이되 **매일 30ml씩 감량**
  (160 → 130 → 100 → 70 → 40)

### 2주차

- **40ml까지 내려가면 배고파서가 아니라 습관이다.**
- 그때부터 물리지 말고 **쉬닥법만 15분.** 2~3일이면 끊긴다.

### 금지

**밤수를 갑자기 끊지 않는다.** 낮 총량이 안 채워진 상태에서 끊으면
새벽에 더 자주 깨고 아침에 폭식한다.
