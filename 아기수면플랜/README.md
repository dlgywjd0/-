## 15주 아기 핵심 수치 요약

| 항목 | 기준값 |
|---|---|
| 하루 총 수면 | 14~16시간 |
| 밤잠 | 10~11시간 (침대에 있는 시간은 11~12시간) |
| 낮잠 | 하루 4회, 합계 3시간 30분~4시간 30분 |
| 활동시간(깨어있는 시간) | 1시간 15분~1시간 45분 |
| 수유 횟수 | 낮 5회 + 밤 1~2회 (모유는 6~8회) |
| 하루 총 수유량(분유) | 체중 1kg당 약 150ml, 하루 750~1,000ml |
| 밤중 수유 | 이 시기엔 1회 정도는 정상. 끊을 시기 아님 |
| 이유식 | 아직 아님 (만 6개월 전후, 소아과 상담 후) |

## 시작하기 전에 꼭 알아둘 3가지

1. **울려 재우기(퍼버법·소거법)는 아직 이릅니다.** 대부분의 소아 수면 지침은 생후 4~6개월 이후를 권합니다. 지금은 "울려서 훈련"이 아니라 **잠들 수 있는 조건을 만들어주는 단계**입니다.
2. **고정할 것은 딱 하나, 아침 기상 시간입니다.** 나머지(낮잠·수유)는 기상 시간에 따라 자동으로 따라옵니다. 시계보다 **활동시간(깨어있는 시간)**을 먼저 보세요.
3. **곧 4개월 수면 퇴행이 옵니다.** 보통 생후 3.5~4.5개월. 잘 자던 아기가 갑자기 자주 깨는 시기이며, 지금 만들어 둔 습관이 이때 버팀목이 됩니다.
